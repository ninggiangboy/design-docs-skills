# Vocabulary: English (en)

Language: English · Native name: English · Code: en

This is the canonical vocabulary. Every other locale file has the same keys, the same English column and the same `{placeholders}`. Templates in `references/templates.md` are written with the English values; render them in the output language by looking each heading or label up in the English column. Values joined by ` / ` in `phrase.none` and `ref.joiners` are alternatives.

## Conventions

- Numbers: `1,234.5`; units separated by a space (`10 s`, `500 ms`, `2.5 GB`).
- Dates: ISO `2026-10-05` in metadata and tables; `Oct 5, 2026` in the SDD byline.
- Quotation marks: `"…"`. UI strings shown in documents are quoted exactly as they appear on screen.
- Register: plain, direct technical English; active voice; no marketing words.
