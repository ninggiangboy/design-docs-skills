# Vocabulary: Español (es)

Language: Spanish · Native name: Español · Code: es

Same keys, English column and `{placeholders}` as `en.md`. Render template headings and labels by looking them up in the English column. Values joined by ` / ` in `phrase.none` and `ref.joiners` are alternatives.

## Conventions

- Numbers: `1.234,5` (dot or thin space for thousands, comma for decimals); units after a space (`10 s`, `500 ms`, `2,5 GB`).
- Dates: ISO `2026-10-05` in metadata and tables; `5 de octubre de 2026` in running text; the SDD byline stays `Oct 5, 2026`.
- Quotation marks: `«…»` or `"…"`, consistently; UI strings are quoted exactly as shown on screen.
- Keep established English technical terms when the Spanish one is not in common use (webhook, consumer lag); put code names in backticks.
