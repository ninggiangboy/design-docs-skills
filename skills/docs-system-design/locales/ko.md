# Vocabulary: 한국어 (ko)

Language: Korean · Native name: 한국어 · Code: ko

Same keys, English column and `{placeholders}` as `en.md`. Render template headings and labels by looking them up in the English column. Values joined by ` / ` in `phrase.none` and `ref.joiners` are alternatives.

## Conventions

- Numbers: `1,234.5`; SI units after a space (`500 ms`, `2.5 GB`), Korean units without a space (`10초`).
- Dates: ISO `2026-10-05` in metadata and tables; `2026년 10월 5일` in running text; the SDD byline stays `Oct 5, 2026`.
- Style: plain declarative form (-다 체) for technical documents.
- Quotation marks: `"…"`; UI strings are quoted exactly as shown on screen.
- Keep established English technical terms when the Korean term is uncommon; put code names in backticks.
